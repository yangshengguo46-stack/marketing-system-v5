# A52 用户纠正四例回归

## 问题

E35 在六个系统预写标签的新案例上出现人工正向信号，但用户指出“从卖什么走到人为什么需要它”的表述可能把目标从语义迁移和内容地图带偏。为避免继续根据系统自己的题目证明系统正确，本轮直接回到用户亲自纠正的四个开发案例：水果店、黄金礼品、海鲜源头和重庆火锅底料。

## 原始验收

- 水果店：来源容器去除后，内容主语与内容世界应为“水果”，不得升成零售、挑选、健康生活或消费方式。
- 黄金礼品：对象世界应为“礼品”，观众世界应进入“送礼与人情往来”；黄金是材质，加工是卖方动作。
- 海鲜源头：对象与观众世界都应为“海鲜”；养殖、捕捞、B/C、供应链和行情只影响证据、定位或分支，不得抢主语。
- 重庆火锅底料：底料是中间商品，重庆是地域修饰，内容世界应迁移到“火锅”，再展开种类、历史、地域、民族、各国饮食习惯、人物、事件与冲突。
- 内容地图必须生成挂在正确根下的实际内容节点；只列“种类、时间、人物”等容量轴名称不算地图。

## 运行控制

- 原样使用 E35 候选提示，不修改、不补案例、不加入用户金标。
- 模型固定为 `glm-5-2-260617`，thinking 开启，`low` reasoning effort。
- 每例一个主调用，四例共享一次 Schema 修复；实际 `4 calls / 0 repairs / 8,865 tokens`。
- 只传用户表达与已观察业务事实。标注只在四次调用全部完成后用于人工复核。
- E35 合同本身没有内容地图字段，因此即使语义通过，也不能判完整功能通过。

## 结果

四例合同均通过，但语义全部失败：

| 案例 | 对象世界 | 观众世界 | 主要故障 |
| --- | --- | --- | --- |
| 水果店 | 水果零售 | 日常水果挑选与消费 | 经营动作和普通消费抢走“水果” |
| 黄金礼品 | 黄金礼品加工与定制 | 黄金礼赠 | 黄金材质与加工仍占主语，没有进入完整礼品及人情世界 |
| 海鲜源头 | 海鲜源头生产与获取 | 海鲜产地实况与市场行情 | 回到旧版 B/C、供应链、行情模板，完全漏掉海鲜对象世界 |
| 重庆火锅底料 | 重庆火锅风味还原与延伸 | 家庭火锅聚餐实践 | 地域风味与家庭场景压窄“火锅”，候选中也没有完整火锅根 |

候选输出的 `capacity_axes` 只是品类、季节、人物、场合等轴标签，没有种类、历史事件、地域文化或跨国饮食等实际展开节点。故人工结论为语义迁移 `0/4`、内容地图 `0/4`、完整验收 `0/4`。

## 判定

E35 不是可采用的语义升级。它把“从名词看动作、从产品看用途、从用途看长期需求”写得过强，导致模型系统性偏爱经营动作、普通使用、场景和需求，而不是比较哪个候选才是最大有效内容世界。

本轮推翻 ADR-015 中“采用双世界注意力方向”的部分，保留 `ca2af9f8` 原版不动。下一候选必须把用途、需求、动作、关系、结果与完整对象放回平等候选位置；选择目标是内容世界，不是需求。语义通过后还必须生成真实的根化内容地图，不能用容量轴冒充地图。
