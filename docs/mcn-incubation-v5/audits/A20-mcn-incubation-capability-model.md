# A20 MCN 孵化能力模型审计

## 结论

MCN 的核心不是批量发布，而是把一个尚未形成稳定公众价值的主体孵化为能够持续生产内容、积累信任并产生商业结果的经营资产。小红书官方 MCN 说明同时包含创作者管理、内容孵化、增长和商业化；MCN gatekeeping 研究把 influencer manufacturing 概括为人才孵化、内容优化和变现三个相互依赖的方向。

因此第五版不能把“策略、内容、发布、数据、媒体”做成并列模块。根必须是孵化判断，其他能力只能成为证据来源、执行器或结果回路。

审计后的完整孵化能力包括：

1. 从当前一句话和已有材料识别主体、目标、资源、能力、产品、权利、限制和关键未知。
2. 分开选择 IP 主体与表达载体。人、品牌、产品和组织都可以由本人、员工、产品演示、场景、旁白或混合方式表达。
3. 从真实问题、欲望和决策情境理解受众，区分目标假设、对标观察和第一方实际信号。
4. 从专有事实、产品机制、可信证明和竞争情境形成可感知定位，并明确战略取舍。
5. 选择匹配镜头表现、可用人物、素材、空间、隐私、成本和持续产能的表现形式。
6. 建立可重复的事件、判断、冲突、证明和转化内容发动机。
7. 同时设计影响目标、行为目标和经济目标；从买方、付费问题、产品、价格逻辑和交付能力形成变现路线。
8. 连接内容、主页、承接物、线索、成交、交付、复购或长期资产积累。
9. 为最重要未知设计最小实验，分别记录内容、受众和商业信号。
10. 根据真实结果修订历史判断，并保留反例、限制和失效条件。

以“宝妈”为例，宝妈只是生活事实，不是赛道答案。会计经验、供应链经验、门店、营养师证书、面点手艺、隐私边界、镜头表现和可售产品不同，应该产生完全不同的主体、形式、内容和变现组合。

## 第五版决定

- 以孵化为唯一根领域，新建独立 `mcn-incubation-core`。
- 产品名称保持未定，内部包名不成为用户品牌。
- 平台、媒体、受众分析和桌面执行后续只能依赖孵化决策或回传证据。
- 将能力清单实现为按需判断视角和评测维度，不实现为固定阶段。
- 先验证个人、品牌和产品孵化判断，再扩展执行层。
