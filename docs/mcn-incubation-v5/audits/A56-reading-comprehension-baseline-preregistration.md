# A56 阅读理解基线对照预登记

## 评测问题

A55 将“语义识别 -> 内容地图 -> 选题生成”重新解释为开放世界营销阅读理解。这个解释目前只是架构假设，不能因为听起来合理就直接进生产。

E39 只回答一个问题：

> 在同一模型、同一次主调用、同一输入和同一输出合同下，显式的“字面阅读 -> 关系阅读 -> 解释阅读 -> 选题收敛”注意力引导，能否比现有 E38 薄选题方法更准确地追踪人物行为、关系、支撑事实和中心命题？

本评测不生成 `MessagePlan`、母稿、口播、短剧、图文或发布方案。只有阅读候选先证明自己优于基线，才能开始后续表达层对照。

## 双臂定义

### 基线臂

- 使用 E38 `generate-content-topic` 的已提交方法文本，以其 SHA-256 作为冻结标识。
- 给定冻结内容根、一条已选地图路径和证据包，直接完成阅读与选题。
- 不使用开发案例、用户金标、新候选方法、记忆、Tool、MCP 或子 Agent。

### 阅读优先候选臂

- 不加知识库、多 Agent、额外调用、基线答案或额外业务知识。
- 在生成中心命题前，显式把注意力放在原路径、来源观察、行为的主体/目标、状态变化、派生解释与未知边界。
- 不要求固定数量的事件、解释、论点或反方；不给评分。

### 公平性

- 模型冻结为 `glm-5-2-260617`，thinking 开启，reasoning effort 为 `low`。
- 每例每臂一次主调用，六例共 `12` 次主调用。
- 两臂共用一份严格 JSON 输出合同，防止候选因为字段更多而获得评审优势。
- 两臂各自全组最多共享一次 Schema-only 修复，供应方总上限 `14` 次。
- 任务乱序执行，不让前一臂输出进入后一臂。
- 记录可见输出、用量、耗时和供应方思考哈希；不保存供应方思考内容。

## 共享输出合同

两臂都必须返回：

```text
ReadingTopicRecord
  supplied_path
    必须逐边保留输入的 from / relation / to
  source_observations[]
    id / claim / evidence_refs
  action_relations[]
    actor / action / target / evidence_refs
  state_changes[]
    subject / before / after / trigger / evidence_refs
  derived_interpretations[]
    claim / based_on_observation_ids / limitations
  topic_brief
    question / central_claim / mechanism / counterpoint / evidence_refs
  unknowns[]
```

列表可为空，不要求填满。解释必须引用已输出的来源观察；所有证据引用必须来自当前证据包。解析器确定性校验原路径未被改名、id 唯一、引用存在和顶层字段无漂移；它不用关键词决定命题好坏。

## 六个留出案例

全部案例未出现在 E29-E38 的模型提示中。下述人工期待只用于运行后审阅，不进入任何模型消息。

### C1 壁纸与《黄色墙纸》

```text
壁纸 --出现在作品中--> 《黄色墙纸》
```

冻结证据为 Project Gutenberg 原文的三组意译摘要：丈夫/医生限制叙述者工作并安排休养；她逐渐看到图案后的女人；她撕下墙纸、宣称脱身，丈夫晕倒后她继续爬行。

人工期待：墙纸是叙述者被限制、感知恶化与试图挣脱的物质焦点/投射面，不是已证明的疾病客观原因；“女人真实存在于墙中”和作者亲口意图均不在证据内。

### C2 书店与《尤利西斯》

```text
书店 --实例--> 莎士比亚书店
莎士比亚书店 --创办者--> 西尔维娅·毕奇
西尔维娅·毕奇/莎士比亚书店 --出版--> 《尤利西斯》
```

冻结证据来自 Princeton Shakespeare and Company Project 与美国国会图书馆：毕奇于 1919 年开设英文书店与借阅图书馆；1922 年由该店品牌出版《尤利西斯》；出版日的原始账簿记录了书店当日销售、会员与支出。

人工期待：书店在这条路径中不只是零售场所，而是能介入作品出版与文化流通的基础设施。不得在当前证据外补造禁书原因、唯一拯救者或销量神话。

### C3 火柴与 1888 年女工罢工

```text
火柴 --生产环节--> Bryant & May 火柴厂
火柴厂 --雇佣--> 女工
女工 --集体行动--> 1888 年罢工
1888 年罢工 --历史联系--> New Unionism
```

冻结证据来自英国国家档案馆：火柴是当时家庭照明与取暖的重要物品；管理层施压并处罚被认为参与行动的工人后，约 1400 名女工离岗；她们在复职、扣薪/罚款等问题上取得结果，随后建立女性火柴工会，该行动成为 New Unionism 的早期重要案例。

人工期待：日常火柴可作为进入隐藏劳动与集体力量的内容入口。火柴本身不是罢工的行为原因；工作条件、管理层行为和工人组织才是事件链。

### C4 制冷、CFC 与蒙特利尔议定书

```text
制冷 --曾使用--> CFC 制冷剂
CFC --科学联系--> 臭氧层损耗
臭氧层损耗 --政策响应--> 蒙特利尔议定书
议定书 --促成--> 制冷剂转型
```

冻结证据来自 NASA 与 UNEP Ozone Secretariat：早期家用冰箱的有毒制冷气体曾导致事故，非易燃且低毒的 CFC 因此得到大量使用；1985 年研究报告南极季节性臭氧损失，1987 年签署的蒙特利尔议定书限制相关物质；制冷与空调曾是 CFC 的主要用户，后续发生多轮制冷剂替代。

人工期待：一种解决家用安全问题的技术方案，如何又暴露出大气层面的隐形代价，并推动科学、政策与产业共同转型。不得将“制冷”整体写成臭氧层破坏的直接原因。

### C5 自行车、女性出行与服装改革

```text
自行车 --技术演变--> 安全自行车
安全自行车 --扩大--> 女性个人出行
女性骑行 --推动/伴随--> 理性服装运动
```

冻结证据来自 Smithsonian：等大车轮、充气轮胎与齿轮等改造使“安全自行车”比高轮车更容易骑行；自行车扩展了部分女性离开家庭的个人流动性，并推动减少笨重长裙和内衬的理性服装运动；但自行车价格高，当时受益者主要是白人与富裕人群。

人工期待：产品技术形态如何改变谁能使用它，进而影响出行、着装与公共可见性。不得宣称自行车已普遍或单独“解放了所有女性”。

### C6 旧照片修复与保留裂痕

```text
旧照片修复 --用户材料--> 撕裂的父母合影
客户 --修复要求--> 修复主体但保留浅痕
```

冻结证据全部标记为用户提供材料：主体从事旧照片修复；客户送来家中仅存的父母合影，照片在多年前一次家庭争执中被撕开，裂缝穿过父亲面部；客户希望修复可见内容，但保留一道很浅的拼接痕迹，因为裂痕也属于这个家庭的历史。

人工期待：修复不一定等于消灭所有损伤痕迹；对某些客户，保留可控的裂痕也是保留记忆来源的一部分。不得补造父母生死、家庭和解、战争、客户成交或传播结果。

## 自动验收

确定性评测只检查可靠于结构的部分：

- 原地图路径逐边完全一致；
- 所有证据和观察引用存在；
- 解释引用的观察 id 存在；
- 隐藏行为三元组中的 actor / action / target 是否同时被捕获；
- 中心命题是否覆盖每例预登记的最小语义组；
- TopicBrief 是否引用预登记必需证据。

中文别名匹配使用完整字段与预登记词族，不使用 E33/E34 已证明会产生错判的任意父子串命中。自动分不能覆盖人工审阅。

## 人工盲复核

每个输出按六项 `0/1` 复核，不评语言风格：

1. **Path fidelity**：没有重选根或改写已给边。
2. **Literal comprehension**：主体、行为目标、时序、状态变化与证据一致。
3. **Relation discipline**：类别、出现、历史联系、触发、解释与现实因果没有混写。
4. **Premise quality**：中心命题说清节点为何值得放在一起，而不是复述资料。
5. **Evidence and inference boundary**：解释不冒充来源事实，没有证据的作者意图、现实因果与效果保持未知。
6. **Counter-reading**：能指出一个真正限制命题的解释，而不是套话或自己编造的反方。

复核前去掉 arm 名称并乱序。系统金标状态为 `preregistered_system_hypothesis`，不冒充用户金标。若案例本身存在多个合理命题，按证据边界接受替代，但不修改冻结自动分。

## 预登记通过线

阅读优先候选只能在同时满足以下条件时声称优于基线：

- 候选零合同失败，两臂供应方调用不超过冻结上限；
- 候选的隐藏行为三元组命中率至少 `90%`，且不低于基线；
- 候选最小语义组命中率至少 `85%`，且命中数至少比基线多 `3` 组；
- 候选六例 TopicBrief 都覆盖该例必需证据；
- 候选人工总分至少 `32/36`，至少在 `5/6` 例上不低于基线，且总分至少比基线高 `3` 分；
- 候选没有事实边界失败；
- 人工收益不是只来自更长输出或同义复述；记录两臂 token 与耗时，但本轮不设成本硬门。

任一条未达标就不声称优于基线。即使全部通过，也只能允许预登记 `MessagePlan -> BaseDraft` 对照，不注册生产 Tool、Skill、中间件、子 Agent 或核心提示。

## 止损与完整性

- 预登记、用例、隐藏期待、输出合同、调用预算与通过线必须在真实调模前提交。
- 实现提示与测试在运行前第二次提交，并记录哈希。
- 正式结果只运行一次；运行开始后不修改题、提示、合同、别名、评分或阈值。
- 如果出现评分器缺陷，保留冻结分数，将缺陷单独入账。
- 供应方、配置、网络或程序故障可以从完整的未消耗任务恢复，不允许拼接不同提示版本的最优输出。

## 结论

E39 是阅读理解架构竞赛，不是写作比赛。它直接检验用户的新判断：在学会怎么说之前，显式把“读懂”做成可见中间产物，是否真能让模型更准确地说出值得说的内容。
