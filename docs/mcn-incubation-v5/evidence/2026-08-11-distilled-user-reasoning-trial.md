# 用户思维蒸馏候选试验证据

## 试验问题

A48 证明宽泛完整孵化方法会干扰纯内容世界探索，但完全移除方法仍不能稳定命中黄金礼品的语义主语。用户随后提出丢掉通用 MCN 核心、改用其在对话中反复纠正的营销思维。本轮只回答一个问题：不复制黄金或水果答案时，这些可观察判断动作能否作为紧凑方法帮助同一个生产 Lead。

候选 `user-distilled-incubation-v1` 只存在于评测模块，正式 `methods.py`、Lead 合同和生产 `incubation_context` 均未改变。其规范化 JSON 为 1,056 个字符，SHA-256 为 `8e4a5ae6fa22c0d6048d39ec3aac791d586d893089d89e0073672b43d5ad1146`；实际 trace 中 1,090 字符的安全工具结果哈希为 `0d9fba0dd104c624d10de655ec1439061833feca1b98e0c9774d499a162d6841`。

## 黄金业务复核

正信号是第一个方向把商品描述为“情感/关系凭证”，第三个方向明确碰到“送礼不知道送什么”。这比 A47 只围绕黄金重要时刻更近一步。

关键锚点仍未命中：回答标题和三个候选继续以黄金为中心，没有先确认礼品/送礼才是更稳定的品类行为，也没有展开送、收、拒、回礼、身份、礼仪、互惠、私人关系、组织关系、历史和国家交往。它继续补造金牌、胸针、印章、花丝镶嵌、3D 打印和 IP 联名等供给，最后又要求选择方向并做小范围测试，越过了当前纯探索任务。因此为 `business-rejected`。

## 水果业务复核

水果从 A47/A48 的三块结构扩成七个候选：“水果生存史”、消费避坑、料理、产地纪实、营养、文化符号和生活美学。历史、产业、人物、现实生活、影视神话和经营回路都被打开，说明蒸馏镜头确实带来可观察改善。

但输出把卡片字段逐项复写成答题表格，每个候选都机械包含语义桥、内容张力、商业回路、反例边界和待核验假设。更严重的是，待核验栏只放“哪类内容表现更好”的泛假设，正文里的历史、供应链、营养、价格和人群主张没有逐项标记。健康顾问、产地纪实、选品标准和联名供给也依赖尚未确认的主体资源。七个候选是探索广度的正信号，不是可直接采用的账号方案，整体仍为 `business-rejected`。

## 因果边界与决定

两例都实际读取了同一候选工具结果，且模型、系统合同、语料、记忆和子 Agent 条件与 A47/A48 对齐，所以可以确认紧凑蒸馏方法改变了输出。每例只有一次采样，三个 run 也不是并发随机对照，不能把所有差异唯一归因于卡片。

黄金和水果正是纠偏方法的来源案例，不是留出集。因此现有证据只支持“用户思维蒸馏有局部方法信号”：它明显帮助水果扩展，却没有解决黄金语义主语、事实边界和模板化回答，更不能证明跨行业泛化。候选不接入生产，也不删除 MCN 下游能力。下一步先离线研究无案例的语义主语反事实检查和非表格式综合，再补留出行业；本轮不继续付费调用。
