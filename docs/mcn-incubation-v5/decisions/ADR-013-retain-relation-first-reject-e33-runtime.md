# ADR-013：保留关系优先，拒绝 E33 直接进生产

- 状态：已决定
- 日期：2026-08-14
- 依据：A45、A47、A48、E32、E33、ADR-012

## 决定

不注册 E33 的关系分析器和左右收敛器。保留“先看最小变体中什么应保持、什么应改变”作为下一候选的注意力控制原语，但必须用新留出集替换 E33，不能在 E33 后面叠第三调用。

## 为什么不进生产

E33 的关系判断 `4/4` 全对，两个对象型对比也全部通过：面包店/卖面包都保留面包，广式/苏式月饼馅都回到月饼。这比 E32 的容器漂移和咖喱一起选错有明显改善。

但冻结分数未过：候选召回和最终收敛均为 `6/8`，低于 `7/8`；全组还使用了一次关系 Schema 修复。虽然其中一个失败是评分器将“日用餐具”中跨字的“用餐”错当禁止词，冻结分数不能事后修改。

更严重的是，自动通过也有假阳性。退休纪念品两侧都选了“退休纪念品定制”，看似包含“退休 + 纪念 + 活动”的验收信号，实际仍是卖方的定制过程，不是观众进入的退休纪念与送别实践。陶瓷毕业礼品也停在产品，没有进入毕业纪念/赠礼。所以“关系判断正确”不等于“两边的根正确”。

人工事实复核同样触发止损：面包答案默认主体会制作且有可用客户反馈；退休纪念品默认主体掌握玻璃/木质工艺并自行补了奖杯、牌匾、摆件等形态；餐具答案将“设计”扩成了“设计与制作”。

## 新的故障位置

当前缺的不再是更多行业知识，而是动作所有者与动作角色的区分：

1. **完整对象**：自身可长期展开时，对象可以是根。
2. **卖方操作或证明**：定制、设计、加工、生产、采购、拍摄等只能证明能力或提供题材，不因为可重复就成为观众根。
3. **买方普通使用**：食用、饮用、烹饪、佩戴、使用等可以是内容发动机，但不自动压过完整对象。
4. **买方/人类反复社会实践或长期结果**：赠礼、送别、纪念等在人物、关系、场合、规则和冲突上比产品目录更完整时，才能升为根。

这是语义角色判断，不是“制作永远不得为根、赠礼永远必须为根”的关键词硬门。

## 下一边界

若继续，下一候选只保留 E33 的关系优先比较，在同一个关系调用中为候选补一个小型“动作主体/角色”标记，然后左右独立收敛。它必须使用新留出案例、边界安全的中文评分器和更严格的卖方事实复核；不重跑 E33，不加第三个 Agent，不建知识库。

## 后果

现役 Lead、`analyze_business_semantics`、`explore_content_worlds`、模型配置与 Gateway 保持不变。关系优先方向获得支持，但 E33 实现本身被拒绝进生产。
