# ADR-009 拒绝单调用分层内容地图

- 状态：accepted-rejection
- 日期：2026-08-14
- 范围：第五版内容结构
- 回滚基线：`ca2af9f8905698a0ad81a204350afa07fb840bcf`

## 决定

不将“来源对象 + 观众世界 + 内容发动机 + 注意力入口 + 稀疏展开”作为一次大模型调用和一个大 JSON 合同接入生产。

现役 Lead、`analyze_business_semantics` 和 `explore_content_worlds` 保持不变。本轮的评测器是未注册的离线试验，不是新运行时、中间件或固定工作流。

## 原因

- 冻结六案例复测只有 `1/6` 完整通过。
- 观众世界会被发动机或局部修饰重新污染，例如医美又缩成面部年轻化。
- 水果和海鲜的根判断正确时，展开轴仍随机漏失。
- 黄金礼品和火锅出现 Schema 漂移；增加重试或放宽合同只会掩盖不稳定。

## 保留的结论

概念上仍保留“四层骨架下挂展开算子”，但不预设它必须由一次模型调用完成。若继续验证，下一候选必须另行预登记，把“冻结四层判断”与“依据已冻结父节点展开”分开比较。这是候选，不是本 ADR 已批准的生产架构。
