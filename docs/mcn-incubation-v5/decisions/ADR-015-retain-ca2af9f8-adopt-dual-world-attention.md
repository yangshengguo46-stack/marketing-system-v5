# ADR-015：保留昨晚原版，采用双世界注意力方向

- 状态：已决定
- 日期：2026-08-14
- 依据：A50、A51、E35、ADR-014

## 决定

保留用户昨晚指定的 `ca2af9f8` 作为完整账号内容结构回滚基线，不把 E35 候选整体注册进生产。

同时采用 E35 证明有效的最小方向：模型先识别来源对象，再分别判断“离来源最近、能独立生长的对象世界”和“观众因什么长期进入的观众世界”。两者允许相同，也允许不同。注意力引导仍使用普通语言里的“从名词看动作、从产品看用途、从用途看长期需求”，不增加固定角色、硬分类、第二 Agent 或知识库必经阶段。

## 对比结果

唯一冻结运行使用同一 GLM、同一组六个新案例和每臂六个主调用。昨晚版出现一次合同失败，观众世界冻结效用为 `6/12`；新候选零合同失败，但精确别名评分给出观众与对象世界均 `0/12`，所以自动门槛未通过。

这个自动 `0` 不是可信业务结论。评分器把“家庭烘焙实践”和“家庭烘焙”、把“淡水钓鱼实践”和“淡水钓鱼”判成不同答案，也漏掉了“古籍保存与延寿需求”“宠物离世哀伤支持”等合理替代。冻结分数不修改、不补别名、不重跑；评分器失效本身进入证据。

逐案人工业务复核不重算冻结分数。新候选在烘焙模具、生日蛋糕、古籍修复和宠物告别四题更好，观赏鱼和淡水钓鱼两题各有范围取舍，未发现昨晚版明确胜出的题。新候选也把用户能力、素材和业务条件放在未知或条件中，没有把它们冒充事实。

## 为什么不整体替换

`ca2af9f8` 已经拥有来源对象、观众世界、内容发动机和注意力入口四层合同；E35 只验证语义核心，没有输出后两层。新候选回答更丰富，但耗时约为原版两倍。把评测 Schema 或候选调用直接叠到生产，会再次形成多层管道，而且会丢掉昨晚版已有能力。

因此本轮只确认“营销脑”的注意力方向，不确认 E35 的评测器或调用形状。下一次生产改动若发生，只能在昨晚版内部做一次最小替换：让原有观众世界判断能够显式区分对象世界与观众世界，然后继续生成原有内容发动机和注意力入口。完整答案用用户业务复核与真实账号结果验收，不能再用精确字符串冒充营销判断。

## 后果

- E35 不重跑、不改隐藏标签、不追加别名，也不拼接局部最佳。
- E35 比较器、Schema 与六个系统假设案例保持离线，不成为 Tool、Skill、子 Agent、中间件或 Gateway 路径。
- `ca2af9f8` 继续是可回滚的完整版本；后续改动必须独立提交，确保可以直接比较和撤销。
- 用户纠正的水果、黄金礼品、海鲜、火锅底料、腕表和医美仍是开发验收证据，不进入运行时上下文。
- 内容发动机、注意力入口、表现形式和商业承接继续各守边界，不被语义模块吞并。
