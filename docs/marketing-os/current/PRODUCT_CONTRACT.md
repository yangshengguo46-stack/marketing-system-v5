# 第五版产品合同

## 产品定义

第五版是一个 MCN 总运营 Agent，服务个人 IP、品牌 IP、产品 IP 和组织 IP。它不只产出文案，而是负责从起号到持续运营的完整闭环。

唯一业务循环为：

```text
业务目标 -> 目标受众假设 -> 市场与对标证据 -> 定位
-> 内容实验 -> 审批发布 -> 真实数据 -> 复盘修正 -> 放大有效模式
```

首批固定平台为抖音、小红书、微信视频号、快手、Bilibili 和 TikTok。官方 API 不是前提，默认通过本地可见浏览器、用户手动登录、账号级持久配置和 MCP 执行。

## 业务真相

下列对象必须分开，不得混成一个“用户画像”：

1. 目标受众假设：尚未被数据验证的经营选择。
2. 对标受众观察：从公开内容和聚合互动中观察到的有限信号。
3. 实际受众快照：指定账号、时间窗口和数据覆盖下的真实聚合数据。
4. 受众推断候选：由 HLLM 或模型基于证据提出的可修订解释。
5. 账号定位决策：用户在 Agent 建议下选择的版本化经营方向。

营销数据库是唯一业务真相源。聊天、文档、浏览器、模型记忆和临时子任务只能保存投影或证据。

## Agent 主权

只有 MCN 总运营 Agent 拥有营销判断权和对用户的最终表达权。研究、分析和制作子任务可以临时委派，但不能改写业务状态、强制路线、拒绝模型继续工作或执行不可逆动作。

策略、选题、脚本、评分、预测和 HLLM 结果都是建议。它们必须展示依据、未知、置信度和替代方案，但不能把营销判断变成代码硬门。

## 安全边界

硬拦截只用于客观安全条件：所有权、账号身份、密钥、版权同意、费用上限、不可逆审批、幂等并发、未知结果对账和有明确来源的平台规则。

发布固定为：

```text
draft -> prepared -> approved -> executing
      -> succeeded | failed | unknown -> reconciled
```

审批绑定用户、账号、内容哈希、素材哈希和有效期。没有第一方作品标识或稳定公开链接时，只能进入 `unknown`，禁止自动重复发布。

## 明确不做

- 电影化 IP、导演工作台和电影生产流程不进入本产品。
- TikTok 达人签约只保留延期需求，首版不实现。
- 不引入第二 Agent 运行时、反检测、验证码绕过、指纹伪装或平台凭证外泄。
- MediaKit 不做营销判断，HLLM 不做流程裁决，UI-TARS 不做自治规划。
