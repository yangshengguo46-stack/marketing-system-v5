## 账号拆解

### 冷启动定位

历史资料与当前证据共同支持：大能起步时不是泛生活达人，而是**有真实制表/玩表积累、能把高门槛腕表讲成人话和人情故事的鲜明个人**。早期突破点不是更密集的参数知识，而是把“撞表”等个人尴尬经历和一本正经的幽默带进腕表内容。专业能力提供可信度，故事和表达降低理解门槛，人物气质提供辨识度。

因此当时的关注主语仍是“懂表且讲表有意思的大能”。腕表是冷启动内容根和信任锚点，不能用他今天的泛生活内容倒推新人也应一开始什么都拍。

### 当前定位

当前账号名称、近期作品和两条完整视频支持将其描述为**玩家型人物 IP**：关注主语已经从“腕表知识”迁移到“大能这个人如何研究、体验、判断和处理各种东西与生活”。腕表仍是身份来源、专业信用和反复回归的锚点，但不再是唯一内容根。

近期 17 条样本横跨腕表、汽车、高尔夫/户外、身体变化、科技开箱、文玩、播客、生活处境和品牌合作。共同点不是同一品类，而是同一个人的体验权、判断方式和表达气质。账号完成了从“品类专家”到“人物即主语”的迁移。

### 内容与表现形式

内容层至少有五类发动机：

1. 借物讲人：从微信签名切入，再谈收到的几块腕表，物品承载身份、关系与选择；
2. 个人经历与强观点：减重、户外和生活体验允许他跨出腕表仍保持人物一致；
3. 稀缺接触与抢先体验：汽车、腕表、科技产品和活动现场提供观看理由；
4. 开放任务与观众共创：断舍离不是展示礼盒，而是把“这些东西给谁”交给观众参与；
5. 商业内容人格化：公开简介有商务入口，近期样本可见 IWC、梅赛德斯、华为、Swisse、海参等品牌/商品内容，但公开证据不能证明合同金额、销量或转化率。

表现形式与上述内容分开：固定机位单人对镜、实物近景、开箱/逐件展示、体验 Vlog、对谈/播客和活动记录。腕表视频采用低制作负担的“正面口播 + 手部近景 + 字幕”；断舍离视频采用“真人出镜 + 逐件展示 + 开放问题”。“历史故事、真实经历、品牌知识”属于内容，不属于表现形式。

### 真正可迁移的孵化方法

不能复制他的发型、语速、表情或今天的品类宽度。可以迁移的是一条有顺序的路径：

```text
真实专长/长期兴趣
-> 找到外行也能进入的人类话题或个人故事
-> 形成稳定、可识别的表达气质
-> 持续证明“这个人真的懂、真的玩、真的做过”
-> 观众开始追随人物而非单一问题
-> 再沿人物的真实兴趣和资源扩展内容世界
-> 商品与品牌成为人物生活中的对象，而不是硬插广告
```

这也补充了第五版账号拆解合同：必须分开输出**获客期定位、当前定位、迁移证据和不可复制条件**。只分析当前热门题材，会把成熟人物 IP 的结果错当成冷启动方法。

## 上下文与运行边界

两条媒体证据生成的 Lead 投影为 `7,745` UTF-8 字节，含 `16` 个候选模式和 `2` 条代表作品，未出现本地路径、图片数据、Cookie、StorageState、原始受众 ID 或完整媒体。完整素材与互动快照留在 gitignored 本地账本，Lead 只按哈希、作品 ID 和证据 ID 按需读取。

本轮通过的是**抖音第三方公开账号的隔离真实验收**：账号身份、作者限定作品、代表媒体、可见互动、账本和 Token 边界均跑通。受众采样额外固定两条覆盖纪律：上限提前用完时只登记真正访问过的作品；未请求 `content_interactions` 时不打开作品或评论页面。抖音短链解析也由回归测试限定为不改变其他平台连接器路由。最终 E15 回归为 `141 passed`，Ruff、格式和 JSON 校验通过。

仍未通过的包括生产 Tool/MCP 注册、定时长期观测、全作品/全评论、创作者后台人口属性、真实 HLLM 推理，以及小红书、快手、TikTok、微信视频号的同等登录态验收；Bilibili 当前仅通过公开搜索 smoke check。
