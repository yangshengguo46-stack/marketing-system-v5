# A07 第四版失败根因审计

## 结论

第四版不是功能太少，而是太多层同时对模型发号施令。359 行 SOUL、通用系统提示词、首次使用中间件、固定访谈、策略/差异化/预演/复盘/晋级阶段、工具白名单和工具轨迹测试一起控制 Agent。

历史收口提交删除了约 1.5 万行语义层，且真实模型基线在大幅减少输入后仍能完成简单任务。这证明问题在控制面，不在模型缺一个新门。最后的未提交救援代码又新增写入校验中间件和工具安全层，属于同一失败模式的重复。

## 迁移决定

- 架构测试永久禁止 Marketing OS 改写宿主提示词、模型请求、工具选择或最终回答。
- 测试不固定工具轨迹和访谈轮数。
- V4 未提交救援代码整体拒绝，只作失败证据。
