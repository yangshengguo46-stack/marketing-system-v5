# A40 营销脑与内容领地审计

## 结论

用户指出的是第五版当前最核心的能力缺口，不是提问数量，也不是发布、账号拆解或表现形式：Agent 要能从一个人、品牌、产品或服务的商业表面，发现它真正参与的人类行为、关系、欲望、仪式和购买情境，再把其中最有商业连续性的部分经营成长期内容领地。

黄金礼品案例的正确起点是：**黄金是材质与价值修饰，礼品是品类中心；礼品的基本动作是送、收、拒、回、选和转赠；这些动作处理的是关系、礼数、身份、亏欠、祝贺、纪念、权力与互惠。**因此账号可以经营“人为什么送礼、礼物如何改变关系”这一大片内容，而不是困在黄金工艺、保值知识或几条送礼技巧里。历史、外交、跨文化、家庭、婚恋、职场、商业和人生礼仪都可以成为题材来源，微短剧、讲述、实物演示、档案解读和观察评论只是后续载体。

这项能力不能写成一套决定答案的算法，也不能塞成核心长提示词。第五版的首选候选是：**唯一 Lead Agent 的营销判断 + 一张按需方法卡 + 有来源的人类机制与购买情境知识 + 项目事实与外部证据 + 真实结果案例记忆 + 专门业务评测。**当前先冻结审计和判别案例，**不修改核心提示词**，不把尚未验证的方法直接接入生产。

## 原诊断为什么偏了

A39 发现的事实补造与提问边界都是真问题，但不是本轮根问题。用户当然需要补充客户结构、利润、资源、镜头能力和交付限制，这些信息会改变账号主体、表现形式和转化方案；可是营销脑不能等所有信息齐全才工作。

只凭“黄金礼品”已经能作出一个高价值、可修订的语义判断：礼品比黄金更接近这个业务要占领的需求入口。后续主体信息决定谁来讲、讲到多深、以什么形式讲、先服务哪类送礼场景，而不是替代这项判断。把失败全部解释成“信息不足”，会让系统退化成会问诊但不会营销的 Agent。

## 第四版做对了什么

第四版隔离研究曾经抓到四个重要洞察：

1. 区分注意、信任、意义和交易锚，具体商品不必承担每条内容的全部功能。
2. 识别中心概念和修饰语，再把名词还原成人的动作、关系和后果。
3. 产品不必每条露出，商业目标不能硬塞进故事人物的欲望和结局。
4. 内容方向必须同时考虑主体归属、持续供给、商业承接和可验证结果。

`scenarios.json` 也明确把“礼品”识别为中心概念，把“黄金”保留为材料与价值修饰。这部分不是失败代码，应当蒸馏为第五版方法和评测语言。

## 第四版在哪里走歪

第四版把正确洞察逐步编译成了中心词 Schema、近中远距离、十二事件发生器、固定故事协议、`absent/causal` 二选一、替换测试、独立校验器和 Writer Brain。随后出现三次关键过度修正：

1. **把深度误写成距离。**场景要求至少两个候选跨出常见送礼语义，路由又只允许 `mid/far`，甚至要求选择语义跨越最大的一项。真正目标应是**最大可占领且能自然回到业务的领地**，不是最大语义距离。
2. **把具体商品和品类行为混成一个商业对象。**`director-loop-scenarios-v1.json` 将黄金、礼品、礼物和首饰一起列为商业对象。为了满足 `absent`，最终连送礼、收礼和礼物都从内容中消失。
3. **把账号级归因压成单集道具测试。**`v2` 尚有送礼者、收礼者和一枚金牌；`v3` 为通过 absent 合同，产出兄妹和解的泛家庭故事，礼品行为完全退出，只在故事外声称观众会把关系理解力归因给黄金礼品经营者。这个归因没有在内容中被持续建立，是人工写回去的商业桥。

用户给出的边界更准确：**具体商品可以不出现，品类行为不能被抽空，品牌归因必须能被账号长期建立。**“句句不提我们的黄金礼品”不等于“句句与礼品、送礼无关”。

## 营销推演对象

这不是固定工作流，而是一组 Lead 可按需展开和回退的判断镜头：

```text
商业对象与经营目标
  -> 品类中心与修饰关系
  -> 人在使用、选择或交换它时做什么
  -> 功能、社会与情感任务
  -> 关系、身份、仪式、权力和风险张力
  -> 真实购买/记忆情境（Category Entry Points）
  -> 多个候选内容领地
  -> 最大可占领且商业连续的主领地
  -> 可持续栏目、题材与表现形式
  -> 账号识别和品牌心智归因
  -> 咨询、购买、交付与结果回收
```

这里的“中心”不是纯语法题，也不保证只有一个答案。Lead 可以同时保留商品中心、使用动作和文化领地等候选，再依据经营目标、主体事实和市场证据收敛。确定性代码只保存候选、来源、版本和结果，不负责宣布哪个词才是真正中心。

`Jobs to Be Done` 提醒我们超越产品属性，观察人在具体处境中要完成的功能、社会和情感进展；Category Entry Points 则提供了从动机、情绪、时间、地点和购买场景建立品牌可想起性的语言。二者可为 Agent 提供镜头，但都不能直接产出账号定位。

## 三种存在必须分开

每条内容和整个账号都要区分：

- **具体商品存在**：某个 SKU、材质、工艺或报价是否在本条内容出现。它可以缺席。
- **品类行为存在**：人是否仍在选择、赠送、接收、拒绝、回赠或解释礼物。经营送礼领地时，它不能长期消失。
- **商业归因存在**：观众为什么会把“懂送礼、懂关系表达、能提供合适方案”稳定归因给这个账号，并在真实送礼情境发生时想起它。

商业归因不要求每条硬植入。它可以由账号名称与简介、持续主题、稳定观点和符号、置顶说明、周期性证明内容、真实方案案例、主页承接和产品内容共同累积。但如果内容本身长期只剩无边界的家庭故事、历史故事或情绪故事，简介里写着黄金礼品也不会自动产生归因。

## 黄金礼品示范

下表是本轮用户确认的专家锚点，不是所有行业的固定模板：

| 层 | 暂定判断 |
| --- | --- |
| 商业对象 | 黄金礼品加工、定制或方案；具体能力仍须向用户确认 |
| 品类中心 | 礼品 |
| 修饰 | 黄金带来的公认价值、郑重、耐久、纪念和成本分量；这些是待核验的品类联想，不是假装已知的企业优势 |
| 品类行为 | 选、送、收、拒、回、转赠、留存 |
| 人类任务 | 表达感谢、歉意、祝贺、尊重、身份、承诺、纪念、边界或互惠 |
| 内容领地候选 | 礼物如何参与人情与关系；可覆盖个人、家庭、组织、国家、历史、跨文化和生命礼仪 |
| 题材发动机 | 谁给谁送、为什么此时送、送什么信号、对方如何理解、收不收、要不要回、关系因此发生什么变化 |
| 形式候选 | 微短剧、历史与外交案例、跨文化观察、礼仪争议、实物故事、方案拆解、无露脸旁白；最终形式服从主体能力与资源 |
| 商业回路 | 观众先形成“这个账号懂送礼与关系表达”的记忆，遇到真实送礼任务时进入主页、方案咨询、定制与交付证明 |

这个方向仍需外部证据和真实实验验证，不保证就是最终定位。人类学资料能支持礼物与互惠、关系和社会生活密切相关，却不能证明某个账号题材一定获得流量或成交。

## 知识应该怎么外挂

不先建一个包罗万象的营销向量库。首轮只需要四类可审计、可按需读取的材料：

1. **人类机制库**：互惠、礼仪、身份、地位、归属、信任、羞耻、亏欠、纪念、边界、风险和人生转折等有来源的机制。它提供联想材料，不替主体贴心理标签。
2. **品类行为与购买情境库**：真实搜索、评论、访谈、成交、平台观察和行业资料中，人们在什么时刻、因为什么任务进入这个品类。事实、推断和创意必须分开。
3. **内容表达库**：微短剧、讲述、观察、实验、档案、过程、证明和对话等形式的适用条件。形式在内容领地之后选择，不能因“口播常见”就默认口播。
4. **结果案例库**：记录主体条件、领地假设、反方向、实际内容、归因信号、线索成交、成本和失效原因。只有真实结果经复核后才可进入案例记忆。

检索先使用现有有界关键词能力；只有在专门检索评测中证明漏召回且 embedding 或混合检索显著改善，才引入向量检索。Anthropic 的上下文工程建议也支持小量高信号基础上下文和即时检索，而不是一次塞入整本手册。

## Agent 怎么思考而不被写死

候选实现采用“先发散、后收敛”，但不建立可拦截请求的阶段机：

- 发散时，从不同人类系统生成少量内容领地候选，允许近、中、远都有；近并不等于浅，远也不等于高级。
- 收敛时比较语义连续性、购买情境覆盖、关系张力、题材丰度、主体可信归属、生产可持续性、可识别性和商业回路。
- 最终给一个主领地、重要取舍、替代方向和最小验证；信息变化后允许重选。
- 评分只用于离线评测和人工讨论，不在运行时变成准入门、排名器或模型输出改写器。

首先用唯一 Lead Agent 和按需方法验证。若真实评测证明发散明显不足，再比较一个只读 `territory explorer`；若商业归因经常断裂，再比较一个只读 `commercial continuity critic`。它们只能返回候选与反证，不能修改项目、决定路线或直接回答用户，也不能被固定要求每次调用。

## 评测设计

`marketing-territory-eval-cases.jsonl` 是这一能力的独立判别集。当前只有 `MT01-gold-gift` 来自用户人工确认，其他案例仅为待专家复核的泛化脚手架，不能冒充 MCN 标准答案。

同一模型、上下文预算和案例至少比较：

1. 当前薄提示词基线。
2. 薄提示词加一张内容领地方法卡。
3. 方法卡加有来源的人类机制与购买情境材料。
4. 同一 Lead 内部先发散、后收敛的两遍候选法。
5. 只有前四种仍不足时，增加有界只读探索或反证子 Agent。

业务评审只看输出能否：

- 区分商业对象、品类中心和修饰，不把语法分析当唯一真相。
- 从产品属性进入人的动作、任务、关系和真实情境。
- 找到足够宽但仍可归因、可经营、可转化的内容领地。
- 产生跨栏目、跨形式、跨时间的内容供给，而不是三个同义选题。
- 说明具体商品不露出时，账号怎样积累品牌记忆并回到成交。
- 随主体资源、客户、证据和结果变化而修订，不套同一个“人类母题”。

黄金礼品的三类关键反例必须同时存在：只讲黄金工艺和参数，过窄；只列送礼技巧，浅而同质；为了追求远联把礼品和送礼完全删除，过远且无归因。测试不要求逐字复现用户答案，也不检查固定推理步骤、候选数量、工具轨迹或故事形式。

## 第五版决定

1. A39 降级为交互与事实边界的次要审计；A40 是当前孵化内核的首要业务缺口。
2. 在改运行时之前，先以黄金礼品专家锚点扩充跨个人、品牌、产品和服务的内容领地评测，并完成人工 MCN 标定。
3. 当前**不修改核心提示词**，不新增中心词解析器、语义距离算法、固定故事协议、运行时评分门、输出改写器或第二 Agent 运行时。
4. 若方法候选通过离线对照，优先新增一张小型、来源化、按需检索的 `content-territory` 方法卡；它提供判断镜头，不规定答案和流程。
5. 不恢复第四版 `absent/causal` 二元合同。第五版明确分开具体商品存在、品类行为存在和商业归因存在，并在单条、栏目与账号三个尺度观察。
6. 人类机制、购买情境和结果案例分别治理；外部资料不能冒充主体事实，成功案例不能自动升级为通用规则。
7. 本轮只完成审计纠正和失败测试，不发起付费模型调用，不把黄金礼品案例记为通过。
