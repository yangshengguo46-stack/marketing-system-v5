# A08 方法技能审计

## 结论

旧版积累了选题、对标、钩子、脚本、传播、受众、发布、复盘和短视频生产方法。这些方法作为 Agent 参考很有价值，但 Skill 不是状态机、数据库或强制工具路由。

电影化、导演、摄影、场面调度和电影类 Skill 不进入营销 Agent 默认能力面。它们在本机可以继续独立存在，但不属于第五版产品。

## 迁移决定

- 营销方法 Skill 按“参考知识”逐个评审，不整包激活。
- 工具只处理业务事实与执行，Skill 只提供方法与检查视角。
- 评分、rubric 和预测只是建议，不得成为硬门。
