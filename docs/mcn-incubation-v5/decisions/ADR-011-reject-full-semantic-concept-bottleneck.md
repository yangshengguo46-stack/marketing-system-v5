# ADR-011：拒绝完整营销语义概念瓶颈进入生产

- 状态：已决定
- 日期：2026-08-14
- 依据：A45、A46、E30、E31

## 决定

不把 E31 的完整语义概念瓶颈注册为 Lead 阶段、Tool、Skill、子 Agent、中间件或 Gateway 路径。保留它揭示的诊断能力：必须把“模型是否想到正确候选”与“模型是否从候选中正确收敛”分开观察。

## 原因

E31 在可解析的四例中都产生了语义上接近金标的候选，黄金还完成了“黄金礼品 -> 馈赠社会实践”的关键跃迁。这证明外置中间概念能让缺失的联想变得可见。

但当前实现没有通过预登记：两例概念合同失败，另外三例分别把水果、腕表和医美过度提升为挑选品鉴、社交玩表和审美保养实践。完整 Qualia、JTBD、框架与社会实践对象把模型注意力推向更理论化的候选；把全部中间态继续交给决策调用，又放大了该偏置。相比 E30，它使用更多 Token 和时间，却没有提高共同口径下的最终根判断。

自动精确词匹配还把“礼仪馈赠社会实践”误判为非“送礼/人情往来”，证明现有评分器不适合单独判断开放语义输出。该缺陷不改变冻结得分，也不挽救本候选，因为合同失败和其他案例回归已经触发止损线。

## 保留边界

- 保留 E31 隔离脚本和测试，作为失败证据与诊断工具，不作为运行时模块。
- 后续评测同时记录候选召回和最终选择，并加入人工校准的语义审阅。
- 不把论文术语直接变成模型可见的长方法卡。
- 不要求每个推断微概念都填写引用；证据纪律应在可核查事实层执行，而不是迫使模型给语义联想伪装来源。
- 若继续，只能预登记一个更薄的普通语言语义格：对象、直接用途、实践/结果候选、返回路径和过度抽象风险。收敛阶段只接收压缩候选，不接收完整理论展开。
- 下一轮必须使用新的留出最小对比集；禁止修改 E31 后重跑同一六例并宣称提升。

## 后果

现役 Lead、`analyze_business_semantics`、`explore_content_worlds` 和 Gateway 保持不变。第五版获得了一个更明确的研究方向，但尚未获得可生产升级的营销语义架构。
