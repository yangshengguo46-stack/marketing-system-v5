# A53 根选择与内容地图一调用整合预登记

## 待证伪假设

E36 证明 E35 的动作、用途与需求偏置会把水果、海鲜和火锅等完整对象改写成普通使用或经营动作。E29 又证明，把四层骨架、发动机、注意力入口与展开节点全部塞进一个大合同会产生注意力竞争和 Schema 漂移。

E37 不叠加 E35 与 E29。它缩成一次调用内的一个完整判断：生成少量真实竞争的内容主语，用实际内容方向而不是轴名称证明容量，选择唯一的最大有效内容世界，并让所有实际地图节点绑定该根。

## 合同边界

只输出五块：来源对象、竞争内容主语、唯一内容世界、根化内容地图节点、未知事项。

- 不区分强制的对象世界与观众世界。
- 不输出内容发动机、注意力入口、表现形式、受众画像、定位、经营、实验或商业承接设计。
- 完整对象、上层完整对象、用途活动、关系实践、结果与文化世界是平等候选，没有“向上更深”的默认顺序。
- 每个候选用实际类别级内容方向展示容量；“种类、历史、人物”等轴名称本身不算节点。
- 最终地图节点只能引用已选候选 id，不能借一个候选 id 后更换术语，也不能挂到未选根。
- 节点是待研究方向，不能编造具体史实、人物结论、医学事实或用户资源。

| 案例 | 正确内容世界 | 地图最低业务要求 |

四例是开发回归，不是未见泛化证据。用户答案、禁止项、必需轴和评语不得进入模型消息。
