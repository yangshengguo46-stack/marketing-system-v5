# A46 营销语义概念瓶颈预登记

## 待证伪假设

E29 与 E30 证明，把一次大回答拆成骨架和展开可以减少部分注意力竞争，但不会自动产生“产品 -> 用途 -> 社会实践”的缺失判断。A45 提出的新候选不再继续拆内容生产阶段，而是把 Lead 通常隐含完成的语义中间态显式化：

1. 第一调用只区分类别、构成、来源动作、用途、人的功能/情绪/社会任务、社会实践和多种候选世界，不选择最终路线。
2. 第二调用读取原始证据和可检查的中间态，选择或推翻候选，只输出来源对象和观众内容世界。

待证伪假设是：正确且可纠正的中间变量，比继续增加内容阶段更可能帮助同一模型完成黄金礼品的语义跃迁，同时不把水果、海鲜和腕表强行拔高。

## 固定控制

- 模型固定为 `glm-5-2-260617`，thinking 开启，`low` reasoning effort。
- 案例、业务表达和证据逐字复用 E29/E30 的黄金礼品、水果店、海鲜源头、重庆火锅底料、腕表和医美六例。
- 模型不可见 `acceptance`、金标词、禁止词、审阅说明和最终评分；隐藏标签只在两次调用结束后运行。
- 两个调用均无示例，不出现六个案例词，不包含行业关键词路由，不读取记忆、Skill、Tool、MCP 或子 Agent。
- 每例两个主调用；概念阶段与决策阶段全组各共享最多一次 Schema-only 修复，主调用 `12` 次、供应方调用总上限 `14` 次。
- 修复只接收字段级合同错误，不接收业务金标，不允许借修复重新做语义判断。
- 第一调用允许概念为空或未知，不规定候选数量，不使用数字评分；第二调用明确把中间态视为可推翻的候选假设。
- 原始可见中间态只保存在 gitignored 的 `.deer-flow/` 运行目录；供应方隐藏思考仅保留哈希。

## 共同评分口径

本轮只评测 E29/E30 与新候选共同拥有的两个判断：

- `source_object`：原始业务对象。
- `audience_world`：观众长期进入的最小完整世界。

不评测内容发动机、注意力入口、八轴展开、定位、呈现、信任、经营或完整起号方案。因此即使本轮通过，也只说明语义骨架候选值得继续，不能声称完整内容地图或营销脑通过。

额外诊断第一调用的 `candidate_recall`：正确观众世界是否已出现在候选中。这样可以区分“中间概念根本没想到”和“已经想到但最终选错”。

## 通过与止损

架构竞赛只有同时满足以下条件才通过：

- 零合同失败。
- 黄金、水果、海鲜、火锅四个用户纠正案例的候选召回和最终选择全部通过。
- 六例候选召回至少 `5/6`，最终选择至少 `5/6`。
- 不出现因强制补齐字段而伪造的主体能力、素材、史实、用户数据或业务数字。

任一用户纠正案例失败、任一合同失败或任一总阈值未达标，候选停止在离线证据。冻结六例只跑一轮，不拼接局部最佳答案，不在运行后增加案例规则。

即使通过，本轮也不注册 Lead、Tool、Skill、子 Agent、中间件或 Gateway 路径。后续必须先做新的留出语义对比集，并验证它不会把概念结构变成固定流程，才能讨论生产探针。

## 对比解释边界

E30 的完整业务验收为 `3/6`；按本轮较窄的来源对象/观众世界口径重新查看冻结结果，水果、海鲜、腕表和医美的根判断正确，黄金错误，火锅合同失败，即 `4/6` 且一次合同失败。这是本轮可比基线。

若 E31 超过该结果，只能暂时支持“显式中间概念与可纠正选择可能改善语义判断”。单轮、单模型、六个已知案例不能证明因果，也不能排除提示措辞、采样波动或案例熟悉度影响。A45 中的最小对比与蜕变测试仍是下一道验证门槛。

## 人工语义复核

冻结分数不做事后修改，但精确词匹配存在明确的开放语义误判：

- 黄金概念阶段已经得到“作为礼品赠送”“情感表达与礼仪交换”“礼仪性馈赠实践”，最终选择“礼仪馈赠社会实践”。这在语义上完成了黄金礼品到送礼/人情世界的关键跃迁，只是没有逐字命中隐藏标签。
- 水果、腕表和医美的概念阶段也分别包含“水果对象世界”“腕表对象世界”和“普通人变美与认同欲望世界”等正确候选，但最终调用没有选择它们。

因此，四个完成两阶段的案例均显示候选召回有价值；最终收敛只有黄金在人工复核中正确。这里的人工复核只用于定位故障，不替代预登记机器分数，也不挽救已触发合同、回归和编造止损线的架构。

## 结论

完整概念瓶颈被拒绝进入生产。它把 Qualia、人的任务、框架、社会实践、候选世界与探针同时暴露给模型，增加了 Schema 面、Token 和理论化候选的注意力权重。把完整中间态继续交给决策调用后，模型更容易选择听起来更完整、更抽象的社会实践，而不是最小有效内容根。

保留的架构学习只有两项：

1. 候选召回与最终收敛必须分开记录；只看最终回答无法判断模型是没有想到还是想到后选错。
2. 下一候选若继续，只能使用普通语言的薄语义格：对象、直接用途、实践或结果候选、业务返回路径、过度抽象风险。完整理论展开不能进入收敛上下文。

E31 不再重跑。下一实验必须另写预登记并使用新的留出最小对比集；现役 Lead、Tool、Skill、MCP、子 Agent、中间件与 Gateway 均不修改。
