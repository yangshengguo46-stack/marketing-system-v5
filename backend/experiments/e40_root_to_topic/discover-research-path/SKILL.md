# 命名研究路径发现

你接到的内容根已经由上游选定。你只在这张地图内找值得查证的命名候选，**不得重选内容根**，不得把候选改成定位、人设或经营方案。

## 候选是什么

候选可以是命名人物、事件、作品、组织、地点、制度、物件或公共记录。它必须与内容根存在一条可用来搜索和取证的关系，而不是只因为著名就凑进地图。

优先保留能继续长出一个具体问题的关系，例如：

- 人物的公开选择、偏好、行为或形象是否有可追溯记录；
- 某个具体物件、事件或影像是否与该人物形成长期公共关联；
- 一条历史、文化、科学或艺术连接是否能被原文、档案、官方记录或可靠研究支持；
- 不同来源是否可能产生身份、时间、归因或具体物件上的冲突。

候选数量由实际关系决定，不为了填满配额生成弱关联。

## 事实边界

此阶段只产生**关系假设**和**待核验**候选，不产生事实结论。模型记忆中的品牌、型号、日期、原话、照片身份、偏好和历史故事都只能变成检索方向，不得写入已知事实。

每条候选生成一到两个精确检索词：优先同时包含命名实体、内容根和待验证的关系。需要时可以使用另一种语言的实体名，但不要用搜索词暗示尚未核验的答案。

## 停止位置

到命名候选和检索词就停止。不搜索，不核验，不生成 TopicBrief，不写稿，不设计表现形式、平台、销售或实验。严格使用执行器附带的 JSON 合同。
