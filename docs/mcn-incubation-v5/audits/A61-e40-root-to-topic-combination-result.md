## 有效信号

丘吉尔路径形成的问题是：

> 丘吉尔与雪茄之间的公共关联中，品牌偏好与“丘吉尔”格式命名这两条线索如何分别形成、又如何交织？

它已明显优于“讲雪茄历史、品牌和产区”的目录式答案：问题绑定具体人物、具体关系冲突和当前证据，并保留了“是否参与设计”“多个规格是否同一概念”等未知。

禁运路径的阅读记录还抓到了肯尼迪在签署禁运前要求购买古巴雪茄的事件，但最终 TopicBrief 又收敛成宽泛的贸易、商标与国际政治问题。这复现了 E39 已发现的故障：模型可以读到最有张力的入口，却可能在最终立题时为了完整和宏大而把它丢掉。

## 真正病根

当前组合是先由模型命名候选，再围绕这些名字搜索。这个顺序有一个封闭瓶颈：

```text
模型没先想到某个人
-> 不会为此人生成查询
-> 搜索只能丰富已知候选
-> E39 只能阅读已冻结路径
-> 下游无法补回漏掉的人
```

因此，E40 证明搜索和阅读能把“已召回路径”做深，却没有证明它们能扩大召回。模型自然选择最显著的丘吉尔，正是本题没有命中较弱联想的原因。

这不是继续给 Lead 加人物清单、雪茄示例或切·格瓦拉提示词的理由。那样只能把本题背熟。下一轮应换一组全新“第一联想与次级联想并存”的留出题，对比：

- 模型先命名、再搜索；
- 先用通用非定向查询取得开放世界候选，再命名和阅读；
- 两路并行召回后，在不看隐藏答案的情况下按可考证性、具体关系和内容张力排序。

文字人物、经典照片和影像线索还应分别测文本搜索与图像/页面证据，不能假定一个文本搜索入口覆盖全部关联。

## 决定

- E40 记录为 `target_failed_directional_bridge_signal_retained`。
- 不注册发现 Skill、E39 方法、固定四段流程、子 Agent 或中间件。
- 不在雪茄题上重跑、换顺序、扩预算或补人物提示。
- 保留命名路径后按需取证、事实/解释分层和有证据 TopicBrief 三个正向原语。
- 下一候选先解决开放世界召回与收敛排序，再讨论完整表达或表现形式。
