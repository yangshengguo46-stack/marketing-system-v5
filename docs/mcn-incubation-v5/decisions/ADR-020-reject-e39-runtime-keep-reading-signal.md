# ADR-020：E39 不进运行时，保留阅读优先的方向性信号

- 状态：rejected_for_runtime_directional_signal_retained
- 日期：2026-08-14
- 依据：A56、A57、E39 冻结实现与唯一正式运行

## 决定

不将 E39 `read-before-topic` 方法卡注册为第五版现役 Skill、Tool、中间件、固定 Agent 阶段或子 Agent；不授权进入生产 `MessagePlan` 实现。

E39 只能被描述为“方向性优于基线”，不能按预登记称为获胜架构。人工盲审从 `23/36` 提升到 `31/36`，但候选未满足行动召回、语义覆盖、必需证据、人工 `32/36` 和零事实边界失败等联合门槛。

ADR-019 继续有效：先读懂、再决定说什么、最后决定怎么说。E39 的失败否定的是当前实现可靠性，不是否定阅读优先的研究方向。

## 保留

- 保留来源观察与派生解释分离。
- 保留行为主体、动作目标、输入路径和反向解释的显式检查。
- 保留相同输入、相同调用、匿名人工复核和不保存供应方思考内容的评测方法。
- 保留“候选召回/结构完整”与“最终命题质量”分开观察，因为 CFC 题再次证明好命题可能掩盖中间记录缺失。

## 拒绝

- 拒绝把四个阅读标签变成每轮强制流程。
- 拒绝为过线而修改这六题、隐藏词族、人工分或阈值。
- 拒绝继续在 E39 上叠提示词、示例、知识库、多 Agent 或第二次正式运行。
- 拒绝用自动精确别名分代替人工语义判断，也拒绝因为自动分存在漏计就忽略已冻结失败。

## 后续边界

任何后继实验必须换全新案例并重新预登记。它只应解决两个已定位问题：

1. 字面记录如何保持为证据可蕴含内容，未知 actor、未来请求和解释性心理机制不得补进事实槽；
2. TopicBrief 收敛时如何保持整条已给路径和必需证据，而不是为了更尖锐的命题丢掉开头节点。

后继方案可以比较单次阅读与一个独立、只读的证据审阅步骤，但在新评测证明额外调用有净收益前，不批准固定审阅子 Agent。
