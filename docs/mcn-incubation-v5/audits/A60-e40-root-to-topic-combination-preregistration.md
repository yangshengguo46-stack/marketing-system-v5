# A60 E40 根到选题组合探针预登记

## 唯一问题

E40 只验证：当上游已将“我是开雪茄馆的，该怎么起号？”收敛为“雪茄”内容根后，将现役地图轴、命名候选召回、受限搜索和 E39 阅读优先 TopicBrief 串起来，能否自然召回用户指定的人物关联，并形成关于人物偏好或经典影像中具体雪茄的可考证选题。

本轮不再测根选择。A59 已证明无歧义原句的 Lead 兜底能选中“雪茄”，同时也记录了现役根工具合同失败。E40 从该已审阅根开始，不用下游成功反向涂改 A59 的工具失败。

## 组合链路

```text
用户原句 + 已审阅内容根 + 现役地图轴
-> 命名研究候选与检索词
-> 按模型输出顺序的受限 Web 搜索
-> 搜索摘要证据包
-> E39 字面 / 关系 / 解释 / TopicBrief
-> 隐藏验收
```

- 候选发现是一次有界模型调用，只输出命名实体、所属地图轴、关系假设、研究价值、检索词和未知。它不得重选根，不得将模型记忆写成已核验事实。
- 候选最多 8 条，这是上限而非配额。执行器按输出原顺序只检索前 4 条，每条最多 2 个查询，每查询最多 5 个结果。
- 不用隐藏人名决定搜索顺序、候选去留或 E39 运行顺序。按候选原顺序对最多前 3 条取得证据的路径运行 E39。
- 搜索结果去重后每条路径最多 8 条证据，单条 claim 最多 700 字符。首版只使用 search_result_snippet，不将摘要冒充原文或第一方证据。
- E39 仍使用冻结的 read-before-topic 方法与 ReadingTopicRecord 合同。路径由候选实体确定后冻结，E39 不得重选根、换边或引用证据包外的 id。

## 隐藏验收

用户在 A58 真实运行完成前给出目标。按用户对“经典叼雪茄照片”和历史人物的描述，本轮将切·格瓦拉、切格瓦拉和 Che Guevara 作为人物实体别名。“窃·格瓦拉”单独出现不能在没有实体消歧义的情况下算历史人物命中。这些别名及下列条件不进入模型消息：

1. 候选发现至少召回一个上述人物别名。
2. 至少一个通过合同的 TopicBrief 同时包含人物、雪茄，并追问偏好品牌或型号，或经典照片中的具体雪茄。
3. TopicBrief 必须引用当前证据 id，并把摘要不能确认的品牌、型号、照片身份或人物偏好保持为未知。
4. 不得因为问题接近用户答案就断言具体品牌或型号已确定。
5. 发现与阅读阶段均无合同失败，不得超过封顶调用数。

全部条件同时成立才记为本题开发通过。这只是用户已给金标的单题开发探针，即使通过也不证明陌生业务泛化，不允许注册生产。

## 调用与冻结

- 模型固定为 glm-5-2-260617，thinking 开启，reasoning effort low。
- 主调用上限是 1 次发现加最多 3 次 E39 阅读，合计 4 次。
- 全组修复上限是发现最多 1 次，E39 所有路径共享最多 1 次；供应方封顶为 6 次。
- 供应方思考原文不持久化，只保存是否存在与 SHA-256。可见输出只保存结构化合同、哈希、用量、搜索证据及来源 URL。
- 正式运行前必须先提交本预登记和红灯测试，再单独实现、冻结哈希并只执行一次真实探针。

## 运行时边界

E40 位于 backend/experiments 与 backend/scripts，不导入 Lead、Tool、Skill 目录、MCP、中间件或 Gateway。通过也只允许建立新的未见对照评测，不直接促进生产。
