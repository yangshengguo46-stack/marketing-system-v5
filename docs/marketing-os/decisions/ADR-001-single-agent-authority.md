# ADR-001：单一 MCN 总运营 Agent 主权

状态：accepted

## 决定

只有一个 MCN 总运营 Agent 拥有营销判断、方向选择和对用户的最终表达权。子任务、模型 provider、Skill、HLLM、MediaKit、浏览器和桌面执行器都是能力器官，不是平行决策者。

## 原因

第四版曾让 SOUL、提示词、中间件、工具、数据阶段、评分器和测试同时决定模型应该怎样工作。结果是模型路线相互冲突，必须用更多硬门修补更早的硬门。

## 执行

- Marketing OS 包不得注入 `SystemMessage`、预制 `AIMessage`、强制 `tool_choice` 或改写模型请求。
- 研究子任务只返回带证据的结果，不直接写入业务真相源。
- 营销建议可以有置信度，但不得把低分数变成拒绝执行。
- 只有客观安全条件能硬拦截，并且每次拦截都必须可审计。
