# ADR-016：拒绝需求偏置候选，恢复语义迁移与内容地图目标

- 状态：已决定
- 日期：2026-08-14
- 取代：ADR-015 中“采用双世界注意力方向”的决定
- 依据：A50、A52、E35、E36

## 决定

拒绝 E35 候选提示及其“从名词看动作、从产品看用途、从用途看长期需求”的注意力权重，不把它融入 `ca2af9f8`，也不把对象世界与观众世界固化成新的必经双阶段。

`ca2af9f8` 继续保持原样作为完整内容结构基线。下一候选的目标恢复为：

```text
业务表达
→ 生成多个可能的内容主语
→ Lead 选择最大有效内容世界
→ 围绕该根展开真实内容地图
```

用途、需求、动作、关系、结果、文化和完整对象都只是语义迁移可能经过的方向，没有任何一种天然更高级。模型可以停在水果、海鲜和腕表，也可以把火锅底料迁到火锅、把黄金礼品迁到礼品及送礼人情世界。判断依据是内容容量、业务特异性和自然返回路径，不是“越像人类需求越好”。

## 推翻依据

E36 原样运行 E35 提示，且没有把用户金标放进模型上下文。四个用户纠正案例全部失败：水果变成零售与挑选消费，黄金礼品仍围绕黄金加工，海鲜变成源头生产与市场行情，火锅被压成重庆风味与家庭聚餐。

这不是评分器误差。四条完整可见答案都没有选中用户确认的内容主语，其中海鲜和火锅甚至没有召回正确根。候选合同也没有内容地图字段，只输出“品类、季节、人物”等容量轴名称，因此完整内容地图同样为 `0/4`。

## 新边界

- 语义迁移负责召回竞争的内容主语，不负责把所有业务升级成需求或社会实践。
- Lead 保留最终选择权，不允许规则、评分或固定角色决定根。
- 内容地图必须挂在已选根下生成实际节点；轴名称不是地图，内容形式也不是内容节点。
- 水果、黄金礼品、海鲜、重庆火锅底料是用户金标开发回归。未来候选必须 `4/4`，但不能把四个答案写进运行时提示。
- 通过开发回归仍不证明泛化；还必须用全新未见案例验证对象保持、中间物上移、修饰词降级和必要的用途迁移。
- 不修改或重跑 E35/E36 来制造更好历史分数。新候选使用新实验编号、先冻结再运行。

## 后果

ADR-015 保留为当时证据，但其采用方向已被本决定取代。E35/E36 均不注册 Tool、Skill、子 Agent、中间件或 Gateway，不进入生产 Lead。下一步不能继续给 E35 叠规则；需要重新设计一个以“候选内容主语与根化内容地图”为直接输出的最小候选。
