# ADR-010 拒绝晋级两步式内容地图

- 状态：accepted-rejection
- 日期：2026-08-14
- 范围：第五版内容结构评测
- 生产基线：`722919f7`

## 决定

不把“先冻结四层骨架，再从冻结父节点展开”接入 Lead、现役 Tool、Skill、子 Agent、中间件或 Gateway 生产探针。

离线评测器可以保留作架构证据，但不得被注册为运行时能力。现役 `analyze_business_semantics`、`explore_content_worlds`、Lead 提示和前端保持不变。

## 原因

- 冻结六例只通过 `3/6`，低于预登记的 `5/6`。
- 黄金礼品没有进入送礼或人情往来，说明最关键的营销语义跃迁仍未建立。
- 火锅发生骨架合同失败，因此零合同失败条件不成立。
- 四个用户纠正案例中只有水果与海鲜通过，核心验收条件不成立。
- 两步调用比单调用更稳定，但每例成本近似翻倍；局部改善不足以支付新增复杂度。

## 保留结论

“骨架选择”和“内容展开”在概念上应保持不同职责；冻结父节点也能防止展开阶段改写根。但下一项研究不能继续靠增加阶段解决营销判断。若继续，待证伪对象应收窄为骨架选择本身，尤其是如何从产品语义比较对象、用途、社会行为与观众长期需求；它仍需离线验证，不能成为固定硬门。
