## 试验问题

A47 观察到黄金礼品与水果的生产 Lead trial 都读取 `content-engine-v1` 和 `incubation-model-v1`，随后回到栏目、角色与完整孵化模板。本次只验证：当 `incubation_context` 不进入模型工具面时，现有极薄营销脑能否更充分打开内容世界。

基线为 `agent-eval-content-world-production-v2-20260811`。消融 run 为 `agent-eval-content-world-no-method-v1-20260811`，experiment 明确密封 `task_mode=content_world` 与 `method_context_mode=disabled`。两组模型、系统合同和语料一致：

## 黄金业务对照

基线把“黄金是承载重要时刻的情感载体”设为核心。消融回答改为“黄金只是载体”，并把第一方向推进到“送什么礼能让对方记十年”的焦虑。这是预设语义中心锚点上的真实改善，支持方法上下文属于**重要干扰源**。

但回答仍分成“仪式感解决方案、工艺档案、价值锚点顾问”三个账号模板，后两项重新以黄金工艺、克重、保值和溢价为中心。它补造胎毛嵌金、十周年金牌、退休纪念章、商务签约金饰等供给与场景，还要求三条内容测试并允许“模拟客户故事”。送、收、拒、回、礼仪、互惠、身份、国家与历史等人情世界没有被充分打开。因此仍为 `business-rejected`。

## 水果业务对照

消融回答明显优于基线：除向上和向下外，首次真正进入杨贵妃、古代水果保存、《西游记》、动漫、未来品种和太空种植，说明极薄营销脑在没有宽泛方法上下文时更容易发挥。

但结构仍被压成三个大块，并继续生成“10块钱”“3个坑”“榴莲的100种吃法”“贵3倍”等任意数字。糖尿病、孕妇禁忌、热量和健康水果属于高风险外部主张，没有浏览器证据或专业边界。回答最后仍按果农/门店/供应链/品牌和表现形式收缩，越过纯探索任务。因此仍为 `business-rejected`。

## 因果边界与决定

两组不是同时随机采样，且项目 ID、时间戳和模型采样可能不同，所以不能把全部差异唯一归因于工具。可是模型、系统合同、语料与业务锚点一致，两例都朝预设方向改善，足以把方法上下文从“可能相关”升级为已支持的**重要干扰源**。

它仍**不是唯一病根**：无方法时仍出现三模板、事实补造、完整交付和未经核验的医疗/价格主张。第五版因此不从生产环境全局删除方法系统，也不把无方法模式晋升为架构胜者。下一步只做任务相关紧凑检索、来源投影和母合同边界的离线设计；新的付费比较需要再次明确确认。
