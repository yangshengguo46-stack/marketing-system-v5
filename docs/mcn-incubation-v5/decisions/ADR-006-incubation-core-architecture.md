# ADR-006 孵化内核架构候选

## 背景

第五版以孵化为根能力，旧 `marketing-os` 不作为产品或代码依赖。第四版已经证明，固定阶段、语义中间件和多层评分同时控制模型会制造冲突。

## 提议

优先验证以下候选，而不是直接宣布采用：

```text
一个总控 Agent
  + 薄宪法
  + 按需方法卡
  + 项目事实账本
  + 项目内受控案例与反例
  + 仅负责计算的确定性分析
```

内容、受众分析、浏览器、媒体、发布和指标系统只能由孵化决策派生任务或回传证据，不拥有孵化判断权。

## 当前状态

尚未产生架构胜者。36 案例和 180 trial 协议已经实现，但真实模型输出、双模型裁判和 MCN 专家校准未完成。

## 接受条件

- 在相同模型、预算和工具面下完成五候选竞赛。
- 个人、品牌、产品分组均无明显退化。
- 编造、刻板印象、虚假保证和隐私风险不高于更简单候选。
- 专家校准表明模型裁判可以用于后续回归。
- 个人、品牌、产品各完成一个真实“判断、实验、结果、修正”闭环。

条件满足后，本 ADR 才能改为 `accepted`；否则修改候选或记录 `rejected`，不得静默改变。
