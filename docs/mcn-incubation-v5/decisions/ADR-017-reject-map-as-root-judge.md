# ADR-017：拒绝让内容地图裁决主语

- 状态：已决定
- 日期：2026-08-14
- 依据：A43、A44、A52、A53、E29、E30、E36、E37

## 决定

拒绝 E37 进入生产，也拒绝“谁能生成更多地图分支，谁就是正确内容主语”的判断方式。

保留 E37 的两个工程合同：最终术语由已知候选 id 确定性绑定；所有内容地图节点只能挂在同一个已选根上。内容地图的职责收窄为展开已经选定的内容世界，不拥有主语裁决权。

## 冻结结果

四个用户开发案例均一次调用完成，零修复、零合同失败，共 `14,897 tokens / 244.963s`。水果和海鲜的主语与地图通过；黄金礼品与重庆火锅底料仍选错，因此语义与正确根化地图都是 `2/4`，没有达到预登记的 `4/4`。

黄金题已经召回“黄金送礼实践”，但最后以业务特异性和返回距离为理由选择“黄金礼品”。火锅题只召回“重庆火锅”，没有完整去掉地域修饰，随后又因担心内容偏向探店而选择底料。两个错误根都生成了七类看似丰富的地图，证明大模型几乎可以替任何名词补出历史、地域、文化和冲突，分支数量和表面丰富度不能证明语义主语正确。

## 结合方式

正确结合不是让内容地图反过来投票，而是：

```text
商业表达的语义拆解
→ Lead 选择并冻结内容主语
→ 内容地图只读取该根并展开
```

语义拆解至少需要让 Lead 看见词法主语、材质或修饰词、卖方动作、部件或中间物与上层完整对象的关系，以及可选的用途或社会框架。它们是可纠正候选，不是固定硬门。业务返回路径是入围条件：完全无法回到业务的根应淘汰；一旦多个根都能自然返回，不能继续奖励“离产品最近”，否则永远会退回商品目录。

内容地图仍可作为反向诊断：若已选根只能生成产品参数和卖方流程，提示 Lead 重新检查根；但地图不能自动推翻或选定根。是否重判仍归 Lead。

## 事实边界

E37 的节点虽然标记 `research_needed=true`，仍写出了具体历史起源、原料产地、地域偏好、工艺传承与效果预测。研究标记不能把编造变成合格。地图阶段首版应输出研究问题或类别级方向；具体人物、地点、历史和医学陈述进入可发布内容前必须另行采集证据。

## 后果

- E37 不重跑、不改提示、不注册生产。
- `ca2af9f8` 保持不动。
- 保留候选 id 绑定、根化父引用和实际节点合同，拒绝 E37 的根选择提示与容量裁决逻辑。
- 四个用户案例继续作为开发回归；E37 的 `2/4` 不能被局部地图质量改写成通过。
- 下一实验如继续，必须先修语义拆解与收敛，再让地图读取冻结结果；不能继续给 E37 叠规则。
