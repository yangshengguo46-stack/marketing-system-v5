# ADR-007 营销脑 80 分目标与学习闭环

- 状态：accepted
- 日期：2026-08-12
- 范围：第五版孵化产品核心

## 决定

第五版的首要目标是将**营销脑**做到稳定可用的 80 分，而不是追求每个视频的机器理解或每次首答都接近 100 分。

这里的“营销脑 80 分”是指：它拿到宝妈、黄金礼品、水果店、果农、品牌或产品的基本信息后，能做出一个像有经验操盘手的孵化判断，而不是套行业模板。至少能处理：

- 选对营销主语：区分产品材质、品类、用途、动作、关系、问题和长期人类需求；
- 建立账号定位：同时考虑 IP 主体、赛道、人设、受众、价值承诺和信任证据；
- 生成内容世界：从主语向上抽象、向下拆分、横向展开和跨维连接，而不是给几个零散选题；
- 分开内容与表现形式：真实案例、历史故事、人情关系等是内容，口播、微短剧、情景剧、Vlog、纯素材图文等是表现形式；
- 从第一版就建立变现逻辑：说明内容如何建立信任、占领何种需求心智，以及产品或服务如何承接；
- 对未知保持未知，在不编造客户资源和数据的前提下给出有依据的候选。

这个 80 分营销脑再进入可交付、可校准、会随真实使用变好的闭环：

```text
项目事实与市场证据
-> Lead 预演孵化判断
-> 用户采用、修改或拒绝
-> 内容创作与版本记录
-> 审批后发布
-> 第一方发布回执与实际数据
-> 复盘区分事实、推断和未知
-> 更新下一轮判断
```

“越用越聪明”必须指这个闭环中的有证据更新，不是自动把模型输出存进记忆、自我强化或对用户承诺保证效果。

## 营销脑的 80 分验收

不用虚构的单一总分冒充精确度。用一组跨主体案例验收这六个业务结果：

1. 是否选对了值得长期经营的主语，并展示从已知事实到主语的推导；
2. 定位、内容世界、表现形式和变现承接是否自洽，而不是四段独立模板；
3. 面对宝妈、品牌、产品、门店和专业服务时，结果是否明显不同；
4. 表现形式是否来自主体、资源、产能和目标的综合判断，不默认口播；
5. 是否清楚标出用户事实、外部证据、营销推断、创意假设、未知和会推翻判断的信息；
6. 专家人工或用户对“主语与定位”、“内容世界”、“表现形式”、“变现逻辑”和“事实边界”五项分别审阅，总体达到可采用或小改后可采用。

黄金礼品是已知正向锚点：`\"黄金礼品\" -> 黄金是材质 -> 礼品是用途 -> 送礼是动作 -> 人情往来是内容世界 -> 黄金礼品是承接解决方案`。但评测不能只靠这一题，也不能将这条路径硬编成所有行业的统一答案。

## 能接受的 20 分不完美

- 第一版定位、内容主题和表现形式可以是有依据的候选，不必一次命中。
- 营销脑在证据不完整时可以同时给出两个有区别的候选主语或定位，而不必伪装唯一正解。
- 首次内容试验可以失败，失败必须留下可比较的方案、成本、回执、指标与复盘。
- 系统可以暂时不知道某个初始判断是否最优，但必须说明依据、风险和什么新事实会使它改变。

## 不能打折的底线

- 用户、项目、账号与素材权利边界。
- 不编造事实、调研、客户案例、业务资源或实验数字。
- 发布前审批、内容/素材哈希绑定、幂等和未知状态对账。
- 发布成功只由第一方作品标识或公开链接证明。
- 实际结果不反推唯一因果，模型推断不自动升格为规则或训练数据。

## 最小产品核心

首个可用版本只需要把四件事做成一条真链：

1. **预演**：Lead 基于已知事实、市场与账号证据，输出孵化判断、依据、未知、备选与可推翻条件。
2. **创作**：将被采用的判断转成内容方案与实际作品，保留策略、稿件、素材和成片版本关系。
3. **发布回执**：通过本地可见浏览器完成审批发布，保存平台第一方作品标识、链接与状态。
4. **复盘**：回收实际数据与用户纠错，明确保留、修改、停止或扩大，并更新下一轮上下文。

MediaKit、账号拆解、知识、Skill、多子 Agent、素材库和日历都只是营销脑完成这四步时需要的能力，不再反过来定义产品。视频理解不是本 ADR 的 80 分对象。
