# A41 田永成医美账号 Agent 拆解审计

## 结论

用户要求让第五版 Agent 自己解析一个医美账号。本轮用隔离 E15 采集器将用户提供的抖音短链转换为作者限定的结构化证据，再把有界证据交给当前生产 Lead `glm-5-2-260617` 独立判断。Lead 抓到了核心关系：**医美仍是品类内容世界根；田永成在该世界中选择“衰老的规律与差异”作为当前可见样本的重点编辑视角；地域、名人、清单和审美词只是内容钩子或内容簇，不能反过来替换品类根。**

这次不是一次性完美通过。第一版正确区分了内容、人物定位与未知的表现形式，也看到了医美项目不是可见内容的主要叙事主角，但随后过度提升“贵气”权重、从互动行为臆测受众动机，并错误描述分享与粉丝关系。给出确定性事实纠错后，同一 Lead 在第二次运行中主动撤回这些结论并完成修订。因此判定为：**核心营销判断通过；首次自主事实纪律仍需校正；端到端链接 Tool 尚未生产化。**

## Lead 自主判断

### 正确抓到的骨架

1. **品类根与编辑视角分离。** 医美是一张完整内容地图；该账号在 39 条可见作品中重点选择衰老、抗衰与外貌变化作为编辑视角。它没有把注射、光电、手术或项目流程当作主要内容目录。
2. **具体钩子没有冒充表现形式。** 地域人群、名人、食物清单、行业争议属于内容；由于没有视频画面，Lead 明确将口播、短剧、Vlog、镜头和制作方式保持未知。
3. **人物信任与内容功能分开。** 账号简介自述 35 年行业经历、组织身份、明星相关经历和机构创始人身份；Lead 将这些视为待核验的人物信任资产，而非已核验事实。
4. **可见内容簇有功能差异。** 地域/人物衰老参照在当前样本中与最高互动相关；行业假案例与行业现象承担内行人信任；稳定的面部年轻化、眼周抗衰、TBM 标签只证明商业对象持续在线，不证明到店或成交闭环。
5. **样本支持而非推翻医美地图。** 账号实际使用了衰老、地域、生活习惯、审美、行业冲突和人物经历等轴，说明内容世界可以大于项目目录，同时仍保持医美品类归因。

### 第一版暴露的错误

- 仅凭少量“贵气”标题，将其提升为独立主轴和“高级地变老”心智，证据不足。
- 将分享和收藏解释成具体的转发动机、未来使用和长期需求，越过了行为观测边界。
- 最高分享 `17,884` 小于粉丝 `116,425`，却写成分享或触达超过粉丝池；且没有播放字段，不能推断触达。
- 将关注 `46` 解读为“只输出不消费”的人设信号，没有证据。
- 将标签稳定出现称为归因闭环，越过了主页入口、私信、线索、到店与成交未知。
- 把地域群体、名人外貌、营养清单和未经核验的医学数字直接列成可复制策略，低估刻板化、名誉、医疗事实和平台风险。
- 修订版仍出现一次简单桶计数错误，说明聚合统计必须由确定性代码提供，不能依赖模型心算。

## 可迁移判断

真正可迁移的不是“香港人老得慢”“名人抗衰”“十种食物”或固定疑问句，而是下面的推理语法：

```text
品类完整内容世界
-> 根据主体专业信用与商业承接选择一个重点编辑视角
-> 用人物、事件、比较、冲突和生活场景生成具体内容
-> 分开设计传播内容、信任证明与需求承接
-> 让商业对象持续可归因，但不强迫它成为每条内容主角
-> 用真实数据复盘视角与钩子，不把相关性写成因果
```

田永成的长期履历、组织身份、明星关系、机构能力和 TBM 品牌不可复制；同行只能根据自己的真实能力重做“为什么由我来讲”的信任结构。高互动的地域、名人和医学内容只能作为待验证候选，发布前必须核验事实、权利、伦理和平台边界。

## 强变现证据缺口

“粉丝十万级但变现极强”目前仍是用户提供的可信业务线索，不是平台验收事实。最小确认集包括：主页或私信承接入口、有效咨询/预约、到店、成交、客单与复购，以及内容/时间窗口与线索的归因。播放、点赞、分享和收藏不能替代这些业务结果。
